#
#   cmdline_additions.txt — Kernel Parameters for Core Isolation
#   Author: bugrASl
#   Date:   April 2026
#
#   INSTRUCTIONS:
#       sudo nano /boot/firmware/cmdline.txt
#
#       IMPORTANT: cmdline.txt must be ONE SINGLE LINE.
#       Do NOT create a new line. Append these parameters to the
#       END of the existing line, separated by spaces.
#
#   EXISTING content looks something like:
#       console=serial0,115200 console=tty1 root=PARTUUID=... rootfstype=ext4 ...
#
#   ADD to the END of that line:
#

isolcpus=1,2,3 nohz_full=1,2,3 rcu_nocbs=1,2,3

#
#   WHAT THESE DO:
#
#   isolcpus=1,2,3
#       Removes Cores 1-3 from the Linux CFS scheduler.
#       No process runs on these cores unless explicitly pinned
#       with taskset. Core 0 handles all Linux housekeeping.
#
#   nohz_full=1,2,3
#       Disables the 250 Hz scheduler tick on isolated cores.
#       Zero timer interrupts during busy execution = tickless mode.
#       Without this: ~3 us jitter per tick × 250/sec = 0.75 ms/sec wasted.
#
#   rcu_nocbs=1,2,3
#       Moves RCU (Read-Copy-Update) callback processing to Core 0.
#       RCU callbacks are Linux's memory reclamation mechanism.
#       Without this: 10-100 us stalls on RT cores when kernel reclaims memory.
#
#   VERIFICATION (after reboot):
#       cat /sys/devices/system/cpu/isolated
#       Expected output: 1-3
#
